Guía Definitiva de Selectores CSS

Resumen completo basado en los niveles de CSS Diner para dominar la selección de elementos HTML.

1. Selectores Básicos

Selector de Tipo: etiqueta

Selecciona todos los elementos HTML que coincidan con el nombre de la etiqueta.

Ejemplo: plate selecciona todos los platos.

Selector Universal: *

Selecciona absolutamente todos los elementos de la página.

Ejemplo: * selecciona todo.

Selector de ID: #id

Selecciona un único elemento específico que tenga ese identificador.

Ejemplo: #fancy selecciona el elemento con id="fancy".

Selector de Clase: .clase

Selecciona todos los elementos que compartan una clase determinada.

Ejemplo: .small selecciona todos los elementos pequeños.

2. Combinadores y Relaciones

Selector Descendiente: A B

Selecciona todos los elementos B que estén dentro de un elemento A (en cualquier nivel de profundidad).

Ejemplo: plate apple selecciona las manzanas que están dentro de cualquier plato.

Selector de Combinación (Múltiple): A, B

Selecciona varios elementos independientes a la vez agrupándolos por comas.

Ejemplo: plate, bento selecciona todos los platos y todos los bentos.

Selector de Hijo Directo: A > B

Selecciona los elementos B que sean hijos directos (primer nivel interior) de A.

Ejemplo: plate > orange selecciona solo las naranjas que están directamente sobre un plato.

Selector de Hermano Adyacente: A + B

Selecciona el elemento B que está inmediatamente después y al mismo nivel que A.

Ejemplo: plate + apple selecciona la manzana que está justo al lado/después de un plato.

Selector de Hermanos Generales: A ~ B

Selecciona todos los elementos B que se encuentren después de A compartiendo el mismo contenedor padre.

Ejemplo: bento ~ pickle selecciona todos los pepinillos que aparecen después de un bento.

3. Pseudo-clases (Posición y Orden)

Primer Hijo: :first-child

Selecciona un elemento que sea el primer hijo directo de su contenedor.

Ejemplo: plate :first-child selecciona el primer objeto dentro de un plato.

Último Hijo: :last-child

Selecciona un elemento que sea el último hijo directo de su contenedor.

Ejemplo: orange:last-child selecciona la última naranja de una torre.

Único Hijo: :only-child

Selecciona elementos que no tienen hermanos (son los únicos dentro de su padre).

Ejemplo: apple:only-child selecciona manzanas que están solas en su contenedor.

N-ésimo Hijo: :nth-child(n)

Selecciona un elemento basándose en su posición numérica exacta dentro de su padre (empezando desde el 1).

Ejemplo: plate:nth-child(3) selecciona el tercer plato.

N-ésimo Hijo desde el final: :nth-last-child(n)

Igual que el anterior, pero contando de abajo hacia arriba o de derecha a izquierda.

Ejemplo: bento:nth-last-child(2) selecciona el penúltimo bento.

N-ésimo de un Tipo: :nth-of-type(n)

Selecciona el n-ésimo elemento de un tipo específico de etiqueta, ignorando a los demás.

Ejemplo: plate:nth-of-type(2) selecciona el segundo plato.

Primer Tipo: :first-of-type / Último Tipo: :last-of-type

Selecciona el primer o último elemento de ese tipo específico dentro de su contenedor.

Ejemplo: orange:first-of-type

Elemento Vacío: :empty

Selecciona elementos que no contienen ningún otro elemento ni texto en su interior.

Ejemplo: bento:empty selecciona cajas bento vacías.

4. Pseudo-clases de Negación

Negación: :not(selector)

Selecciona todos los elementos que no coincidan con el selector indicado entre paréntesis.

Ejemplo: apple:not(.small) selecciona las manzanas que no tienen la clase small.

5. Selectores de Atributos

Tiene Atributo: [atributo]

Selecciona cualquier elemento que contenga ese atributo, sin importar su valor.

Ejemplo: [for] selecciona elementos que tengan el atributo for.

Valor Exacto: [atributo="valor"]

Selecciona elementos cuyo atributo coincida exactamente con el valor especificado (sensible a mayúsculas).

Ejemplo: [for="Vitaly"] selecciona elementos cuyo atributo for sea exactamente Vitaly.

Empieza por: [atributo^="valor"]

Selecciona elementos cuyo valor de atributo comience con esos caracteres específicos.

Ejemplo: [for^="Sa"] selecciona nombres que empiezan por "Sa" (Sam, Sarah).

Termina en: [atributo$="valor"]

Selecciona elementos cuyo valor de atributo termine con esos caracteres.

Ejemplo: [for$="ato"] selecciona nombres que terminan en "ato" (Hayato, Minato).

Contiene (Comodín): [atributo*="valor"]

Selecciona elementos cuyo valor de atributo contenga esos caracteres en cualquier parte.

Ejemplo: [for*="obb"] selecciona nombres que contienen "obb" (Robbie, Bobby).
